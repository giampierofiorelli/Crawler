# Price-free isolated research package (Phase 63)

This research artifact includes price-free synthetic ranking, documented source-review checks, and an approved-link resolver. Callers MUST supply `purpose: synthetic_demo` and documentary approvals. Public deployment is BLOCKED until real measurement normalization and source rights are independently validated. It is not a deployed web application. No Amazon API data or MSRP/RRP is used. Inputs and rights approvals in demos are synthetic.

Import `buildLaunchRecommendation` from this package; do not load any historical research source files. Retailer prices and affordability are not evaluated. Verify current price directly at the retailer.

Phase 63 original-test lineage and earlier experimental contextual functional suitability modules are deliberately NOT included. This package remains an older synthetic demo pipeline, not a validated consumer recommendation engine. Not a legal-compliance certification; no merchant contracts or real retailer destinations have been independently approved.
