## Real evaluation protocol (blocked until performed)

1. Secure an acceptable access basis for each video/transcript; log the provider,
   scope and revocation rules. Do not scrape unreviewed copyrighted content.
2. Have two *independent* annotators view the video or inspect legitimately
   available source content before seeing PEE predictions. Record reviewer IDs,
   their distinct receipts, exact criterion and variant, and timestamp.
3. Label claim kind, task-specific expertise supported by independent sources,
   model/variant match, original measurement genealogy, commercial disclosure.
   Unknown is a valid annotation, not a failure to be auto-filled.
4. Distinguish article copies, transcript translations and same-experiment reports;
   annotate event pairs only where the relationship is actually reviewed.
5. Run the original Phase205 native provider on the same permitted inputs; only
   then compare YouTube.js, youtube-transcript-api and PyABSA where technically
   and contractually feasible. Record retrieval failure, runtime, latency, size,
   memory and human-review effort alongside extraction quality.
6. Report false merges, omissions, abstentions, inter-annotator disagreements,
   missing-source rates and changes to the Phase197 sufficiency decision.
   Re-test on held-out creators, categories and temporal revisions.

The distinction between source documents and underlying experiments follows
[Cochrane guidance](https://www.cochrane.org/node/97); conservative stopping
requires uncertainty disclosure (https://pmc.ncbi.nlm.nih.gov/articles/PMC11583672/).
