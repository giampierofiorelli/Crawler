# Phase196 Source Intelligence pilot

**Canonical source:** `src/phase196_source_intelligence.ts`. **Evaluation:** `src/phase196_evaluation.ts`.
Seed: `data/phase196/publisher-method-seed.json`. Demo: `scripts/phase196_demo.mjs`.

Input must be an existing `BatchResult195`, existing Phase193 ledger, a strictly validated publisher-method seed, and scoped operator annotations. `sourceRevision` plus actual new publisher-byte input optionally reaches `checkFreshPublisherSnapshot194`. Without it, a historical exclusion or endorsement cannot be reused for a fresh article.

Output is research planning only. Known-method scope is a prior for where to LOOK, never an evidence weight. Unknown sites may compete, stars-only pages remain discovery-only, and rare products remain visible. The selected queue never changes Phase182 permissions or Phase181 rankings. The source/original experiment provenance remains unverified.

For evidence basis, verified software tests, limitations, and links to the methodological sources, see root `PHASE196-TECHNICAL-REPORT.md`.
