# Third-party text in this directory

The request texts in these files are excerpts of questions posted on Stack Exchange:

- `journey-real-requests.json`
- `journey-real-requests-set2.json`
- the files whose names start with `journey-real-requests` and end in `results*.json`
- the files under `journey-dev/` named `real1-*`

They are shared under the Creative Commons BY-SA licence version given for each case (CC BY-SA 2.5, 3.0 or 4.0). Each
case in the two benchmark files names its author and links the original question. The result files repeat the same
texts and are covered by the same attribution. All other content in this directory is PEE's own work.
